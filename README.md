# Arun & Nisha — Wedding Invitation

An animated, mobile-first wedding invitation for Arun and Nisha, Varanasi, 20 December 2026.

- `index.html` — the invitation: velvet envelope with Ganesha seal, Ganesh vandana card, animated varmala, baraat and saat phere clips, rasmein, Kashi guide, dress code and shehnai music.
- `assets/` — artwork, motion clips and music used by the invitation.
- `moodboard/` — the design moodboard.

Open `index.html` through a local server so the videos and music load, for example:

```bash
python -m http.server 5180
```
